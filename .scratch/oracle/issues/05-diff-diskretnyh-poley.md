# 05 — Дифф трасс по дискретным полям и белый список

Status: ready-for-agent
Type: task

**What to build:** главный инструмент вехи. Читает две трассы и печатает **первый разошедшийся тик** —
номер тика, имя поля, значение эталона, значение порта и контекст в несколько тиков вокруг. Этого
достаточно, чтобы закрыть приёмку фазы 5: выбор клипа либо совпал, либо нет.

**Почему первый тик, а не список всех.** Первый разошедшийся тик по определению есть место первого
отступления, всё дальнейшее — его следствие. Это бисект по времени вместо бисекта по коду, и именно он
снимает потолок на размер портируемого куска. Полная таблица расхождений не печатается никогда: отчёт,
который не читают, не отличается от отсутствующего.

**Что сравнивается точно:** `anim_name`, `anim_type`, `function_type`, `frame_num`, `foot`,
`enum_velocity`, `touch_frame`, `quadrant_id`. Клип сравнивается **по имени**, а не по индексу —
целочисленные `anim_id` несопоставимы, пока не сошёлся манифест (тикет 04); при сошедшемся манифесте
`anim_id` берётся как быстрый точный ключ. `controlled` в этот список не входит: он ключ отбора строк,
и на спаренных строках равен 1 с обеих сторон по построению.

**Как спариваются строки.** `P`-строки — по (`tick`, `controlled = 1`); `player_id` печатается
справочно и в спаривании **не участвует**, потому что нумерация сторон независима (у эталона — id
внутри команды, у порта всегда 0). Строки эталона с `controlled = 0` на фазе 5 игнорируются молча — их
у порта нет по построению, их число печатается в шапке отчёта. `B`-строки — по `tick`.

**Постоянство контролируемого.** Перед сравнением инструмент проверяет, что во всей трассе эталона
`controlled = 1` стоит у одного и того же `player_id`. Иначе — отдельный вердикт «контроль переезжал»,
построчный дифф не запускается: строки принадлежали бы разным людям. (Сценарии `Switch` не содержат —
парсер его запрещает, — но проверка дешёвая и ловит любую другую причину переезда.)

**Коллизия имён автогенов.** Синтезированные имена не уникальны — формула грубо квантована. Пара
`anim_name` + `foot` разрешает почти все случаи; неразрешённые дубли инструмент берёт **из манифеста**
(тикет 04 их уже посчитал), печатает их число в шапке отчёта как ограничение прогона, а строки, чьё имя
попало в такой дубль, сравнивает по `anim_id` — он законен, раз манифесты сошлись.

**Белый список** — `tools/trace_whitelist.txt`, машиночитаемая выжимка из
`docs/wiki/расхождения-с-оригиналом.md`. Строка = `<колонка>|<условие>|<ссылка на строку страницы>`, где
условие — `always`, `tick<N`, `tick>N` или `kind=B`; `#` — комментарий. Ведётся руками, и расхождение,
у которого нет строки на той странице, в список не попадает. Без него дифф зашумляется известным и его
перестают читать.

**Сценарий вышел за безопасную область.** Если в любой из трасс встретилась строка с `touch_frame >= 0`
или дистанцией игрок-мяч меньше 10 м, отчёт печатает предупреждение: до фазы 8 такие участки отравлены
незакрытыми швами (`MentalImage`, суррогатный `HasPossession`, `AI_GetPass`), и расхождение на них не
приговор порту.

**Blocked by:** 04 — до вердикта по манифестам построчный дифф трасс показывал бы расхождения, которых
в портированном коде нет.

- [ ] Инструмент читает две трассы, белый список и вердикт по манифестам
- [ ] Совпадение: печатает «совпало на N тиках» и завершается нулём
- [ ] Расхождение: печатает тик, поле, оба значения и контекст ±5 тиков, завершается ненулём
- [ ] На первом расхождении дискретного поля фиксируется тик `T` и дискретный слой дальше не
      разбирается, но чтение трасс продолжается — ради контекста `±5` тиков и ради непрерывного слоя
      (тикет 06), который считается на всей длине
- [ ] Строки спариваются по (`tick`, `controlled = 1`), `player_id` в спаривании не участвует
- [ ] `controlled = 1` у разных `player_id` в одной трассе → вердикт «контроль переезжал», построчный
      дифф не запускается
- [ ] Поле из белого списка исключено из отчёта, остальные поля продолжают сравниваться
- [ ] Неразрешённая коллизия имён автогенов отмечена как ограничение прогона, такие строки сравнены
      по `anim_id`
- [ ] Касание мяча или дистанция до мяча меньше 10 м в любой из трасс → предупреждение о выходе за
      безопасную область фазы 5
- [ ] Отчёт помещается на экран при любом входе
- [ ] `tests/check_trace_diff.gd` на синтетических трассах, собранных в самом тесте (не на золотых
      файлах с диска): идентичные → ноль; расхождение на известном тике → назван именно тот тик и
      именно то поле; поле из белого списка → исключено; `controlled` у разных `player_id` → вердикт
      «контроль переезжал»; трассы разной длины и трасса с пропущенным тиком → внятная ошибка, а не
      молчаливое усечение

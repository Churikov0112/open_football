# Белый список диффа трасс — машиночитаемая выжимка из docs/wiki/расхождения-с-оригиналом.md.
#
# Формат строки: <колонка>|<условие>|<ссылка на строку страницы>
#   колонка  — имя колонки трассы из заголовка (anim_name, foot, pos_x, ...)
#   условие  — always | tick<N | tick>N | kind=B
#   ссылка   — строка таблицы на странице, по которой правило заведено
# `#` — комментарий. Ведётся руками: расхождение, у которого нет строки на той странице, сюда
# не попадает. Поле правила исключается из отчёта, все остальные поля продолжают сравниваться.
#
# СЕЙЧАС ПРАВИЛ НЕТ, и это разобранный результат, а не незаполненный файл. По таблицам страницы:
#
# Постоянные:
#   AABB-коллизии мяч↔тело, touch_bodypart по ближайшей кости — видны только через касания, а
#     сценарий приёмки фазы 5 мяча не касается; сам факт выхода за эту область дифф печатает
#     отдельным предупреждением, а не гасит полем.
#   Шейдеры, UI по функциям, поле в размерах FIFA — презентация, в трассе колонок нет.
#   «RED ALERT» перезапускает клип вместо exit(1) — ветка срабатывает на пустой коллекции отбора,
#     то есть эпизодически и по всем анимационным полям разом; полем не выражается.
#   Uniform достигает max с вероятностью ~2⁻²⁵ — на длине прогона фазы 5 не наблюдаемо.
#
# Временные:
#   Разные потоки случайных чисел у сторон (генератор уже общий) — правила не даёт: разные
#     потребители одной последовательности отравляют все поля разом, а не колонку. Спека снимает это
#     требованием к сценарию (вдали от мяча, без кнопок действия), а не белым списком. Снимается
#     фазой 9.
#   MentalImage, суррогатные швы матч-слоя, AI_GetPass/AI_GetShotDirection — то же: незакрытый шов
#     отравляет все поля разом. Спека закрывает их требованием к сценарию (вдали от мяча, без
#     кнопок действия) и предупреждением о выходе за безопасную область, а не белым списком.
#   Статы 0.6 и zMultiplier — закрыты точкой патча 6 эталона, расхождения нет.
#   Сетка ворот — презентация, в трассе колонок нет.

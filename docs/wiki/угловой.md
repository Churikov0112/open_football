# Угловой (Фаза A — `corner_controller.gd` + `corner_logic.gd`)

Общий контур стандартов, intent-шов, гейтинг — см. [[стандарты-и-intent-seam]].

## Что это

Реальный запуск — **судьёй** (`restart_awarded(CORNER)` → `_dispatch_corner`; судья не делает интерим
для CORNER, как и для goal-kick/throw-in). Плюс клавиша **C** (`corner_debug`, ручной запуск человеком,
гейт `_keeper_at(-field_length) != null and not _celebrating`). Контроллер **сторона-агностичный**:
атакующая команда — по группе бьущего (`_att_group`/`_def_group`), сторона — `side_override` от точки
судьи (`signf(spot.x)`) либо по X бьющего при C-запуске. Автомат `IDLE → SETUP → AIM → STRIKE` (без
WATCH; на `_release` обычная камера возвращается сама). Две опции: **наземный пас** (`pass_short`/A) и
**навес** (`pass_lob`/B), плюс **короткая опция** (`corner_call` — позвать партнёра).

## ИИ-подача (`CornerPlan` + `AICornerIntent`)

При team_2 (ИИ) диспетчер `_dispatch_corner` собирает решение и проигрывает его тем же intent-швом:

- **`CornerPlan`** (чистый скорер, не читает FootballConstants) — **lob-first**: навес (variant 1) на
  реального тиммейта в штрафной предпочитается, наземный короткий пас (variant 0) — только когда цель
  слишком близка для навеса (вне нижней кромки lob-диапазона + `AI_CORNER_LOB_BIAS`) И коридор чист
  низом (`PassSystem.interception_time`). Возвращает `{index, variant, power_ratio, aim_dir}`; при
  недостижимости — самодостаточный фолбэк (навес в створ, ratio 0.5). Цель — box-позиция тиммейта
  (`short_mate_start_pos`, ту же выставит контроллер).
- **`AICornerIntent`** (`extends KickerIntent`, читает FootballConstants) — directional-playback как
  `AIGoalKickIntent`: думает `AI_CORNER_THINK_TIME` → доворачивает heading стиком на `aim_dir` (через
  `CORNER_AIM_SPEED`/`_ARC`) → заряжает под `power_ratio` → отдаёт `variant` → коммит. Короткую опцию
  (`secondary`) ИИ v1 **не зовёт**, curl не крутит.
- Презентация — `Role.NONE` (камера не трогается). Бьющий — ближайший полевой атакующей команды к флажку
  (`_nearest_outfielder`).

## Живая защита человека (ИИ-угловой)

При `Role.NONE` человек **не заморожен** — защищается своей командой (аналогично [[ввод-от-ворот]],
[[начальный-удар]], [[вбрасывание]]): морозится только подающая команда (team-scoped
`set_field_ai_active(false, _att_group)`), `_physics_process` проваливается в обычную игру, пока
`!camera_is_owned()`; подкат/дриблинг/суд глушит общий `_live_defend_setpiece_active()`. Заход в дугу
держит невидимая стена **`CORNER_DEFEND_DIST`=9.15 м** (Law 17) — цилиндр на `SETPIECE_BLOCK_LAYER`,
который слушают только защитники (временный бит в mask), упираются и слайдят через `move_and_slide` без
телепорта (тот же приём, что стена 2 м во вбрасывании). Декоративная толпа/защитники при ИИ-угловом **не
спавнятся** (поле живое — фейковые фризнутые тела путались бы с реальными); остаётся один реальный
получатель-тиммейт. Управление получателю **не** передаётся (`owns_hud()` false — ИИ подберёт мяч сам).

Высота навеса — по стику-Y: head/standard/свеча (все садятся в одну точку, отличается время полёта).

## `CornerLogic` (не читает FootballConstants)

- `side_for_player(player_x)` — сторона +1/−1.
- `corner_spot(side, half_width, goal_line_z, inset, ball_radius)` — точка мяча в углу (на `CORNER_INSET`
  внутрь).
- `foot_for_side(side)` — «открытая» нога (правый угол → левая).
- `peak_for_stick_y(stick_y, head, standard, svecha)` — высота дуги по стику.
- `box_target_positions(...)` · `short_option_pos(...)` · `short_mate_start_pos(...)` — цели/партнёр.
- `runup_dir(side, into, foot, angle_deg)` — направление разбега (зависит от ноги И стороны).

Плюс `FreeKickLogic.base_heading`/`rotate_heading`/`curl_from_stick`, `PassSystem`,
`KeeperLogic.drag_horizontal_speed`.

## Размещение и спавны

Мяч в угол (`corner_spot`, `_pin_ball` до удара). `_runup_dir ≠ _heading` — разбег стартует **снаружи
поля** у флажка. Спавнится временная «толпа» `_spawn_targets` (team_1 цели + team_2 защитники, все в
группе `corner_spawned`, все деспавнятся) + **один реальный тиммейт из ростера** (`_real_mate`/
`_short_mate`) — он и есть единственный получатель и короткая опция. Расчистки соперников по радиусу тут
нет.

## Уникальная гоча

У бьющего временно снимается маска `BOUNDARY_COLLISION_LAYER` (`_kicker_mask_saved`) — он стоит/разбегается
снаружи боковой линии за граничной стеной (x=±34); возвращается на `_release`, где бьющего ставят внутрь
поля. **Состав не растёт:** получатель — реальный ростерный игрок, вся толпа деспавнится
(`_free_all_spawned`) — проверяется тестом `check_corner_no_growth.gd`.

Константы — секция CORNER в [[константы]] (вратарь использует `FK_KEEPER_STEP_OUT`). Тесты:
`check_corner_logic.gd`, `check_corner_plan.gd` (lob-first скорер), `check_ai_corner_intent.gd`
(проигрывание), `check_corner_dispatch.gd` (судья → team_1 human / team_2 AI, без интерима),
`check_corner_defend.gd` (живая защита: стена 9.15 м, team-scoped freeze), `check_corner_flow.gd`,
`check_corner_intent.gd` (также `secondary()`→короткая опция; **launch-зависимый флейк** — 2–3× перед
вердиктом), `check_corner_no_growth.gd`. Спека: `docs/superpowers/specs/2026-07-21-corner-kick-design.md`.

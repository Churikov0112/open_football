# Слайд-подкат и система падения

Всё в [[архитектура|match_manager.gd]], две независимые машины состояний: `TackleState`
(`NORMAL`/`SLIDING`/`RECOVERING`) и `FallState` (`NONE`/`KNOCKDOWN`/`ROLL_1`/`ROLL_2`/`GETUP`).

⚠️ **`_tackle_state` и `_tackle_player` — единые поля на весь матч, не на игрока.** Проверяя «идёт ли
подкат», сравнивай **и** `controlled_player == _tackle_player`, не только `_tackle_state != NORMAL` —
иначе заденешь игроков, не причастных к текущему подкату (кусало в `_handle_player_input`).

## Старт слайда

`_start_tackle(player, target=null)` — человеком через `_try_tackle()` или ИИ через `_poll_ai_tackles()`
(опрос флага `wants_to_tackle` каждого team_2 узла через `_ai_of(node)` — флаг на `simple_ai`-мозге,
не на теле). Лочит мотор подкатчика, играет one-shot `tackle`, целит `_tackle_dir` в `target` (по
умолчанию мяч) с **простым упреждением**: `predicted_pos = target.pos + target_vel *
(distance/SLIDE_TACKLE_SPEED)` — так как мяч lead-follow-ит дриблёра (см. [[мяч-и-дриблинг]]), это ведёт
движущуюся цель, а не бьёт в устаревшую точку. Одна оценка первого порядка, без итеративного схождения.

## Во время слайда

`_tackle_slide()` — тело физически движется `move_and_collide()` (не `move_and_slide()` — одно
намеренное исключение из [[локомоция|нормальной локомоции]]), мотор control-locked, чтобы системы не
дрались.

## Два раздельных, намеренно разных радиуса попадания

Один радиус не служит обеим задачам (либо мажет по мячу, либо роняет с видимого зазора):

- **Досягаемость мяча** — широкая `TackleArea` (`Area3D`, `SLIDE_TACKLE_AREA_RADIUS = 1.5`),
  `body_entered` → `_on_tackle_body_entered()`. Реагирует только на `body == ball` (чистый подкат:
  выбивает мяч `ball.kick()`, завершает слайд). Её `collision_mask` **обязан** включать
  `PLAYER_COLLISION_MASK` (bit2) вдобавок к слою мяча — иначе Area3D (маска по умолчанию только слой 1)
  молча не видит тела игроков.
- **Сбивание игрока** — куда теснее, `_check_tackle_player_hit()`, опрос каждый кадр слайда против
  `get_overlapping_bodies()`, гейт `SLIDE_TACKLE_HIT_RADIUS = 0.9` (≈ сумма радиусов капсул + запас) —
  падение только на видимом контакте, не с ~1.5 м. Физический контакт `move_and_collide()` с
  соперником (проверяется первым, в `_tackle_slide()`) роняет напрямую и безусловно.
- Оба пути зовут `_on_tackle_hit_player(body, normal)` → `_begin_fall(body, normal)`.

## Ещё не фол

`_on_tackle_hit_player()` ставит `_tackle_clean = true` безусловно — штрафной за сбивание не даётся.
Ветка фола (`_tackle_foul_position`/`_tackle_fouled_player`) прошита, но недостижима; нужно правило
«мяч выигран первым vs тело первым» (см. `docs/football_reference.md` §9). См. [[открытые-вопросы]].

## Цепочка падения жертвы

`_begin_fall()` → `_process_fall()`: `KNOCKDOWN` (`fallen_idle`, отброс за `KNOCKDOWN_TIME`) →
`ROLL_1`/`ROLL_2` (`roll_left`/`roll_right`, по стороне удара) → `GETUP` (`standing_up`) →
`_finish_fall()` (снимает группу `fallen`, разлочивает мотор). **Анимационное, не физика.** Ранний
физ-ragdoll (`ragdoll_skeleton.gd`, `PhysicalBone3D`) построен и намеренно выброшен — не дружит с
масштабированным Mixamo-импортом; файл и тесты (`check_ragdoll_*`) живут и проходят, но **активная
игра их не зовёт** — не считай их наличие доказательством, что ragdoll жив. Пока `fallen`, `PlayerMotor`
не трогает вертикаль (см. [[локомоция]]).

## `IN_PLACE_CLIPS` в `tools/merge_mixamo.py`

Замораживает root-motion трансляцию на конкретных **Blender-local** осях для `tackle`/`roll_left`/
`roll_right`, чтобы запечённая mocap-трансляция не дублировала ручной `move_and_collide()`. Ошибка в
выборе оси **не выглядит как ось-баг** — выглядит как «игрок парит/висит в воздухе». `automatic_bone_
orientation` разворачивает локальные оси кости от мировых, а glTF-экспорт ещё переставляет индексы →
«индекс 2 = вертикаль» (старое допущение) было неверно дважды. Меняешь `IN_PLACE_CLIPS` — проверяй
эмпирически (сэмпли `Position3D`-трек собранного glb через `Skeleton3D.get_bone_pose()`), не доверяй
допущениям об индексах осей.

Тюнинг — секции SLIDE TACKLE / TACKLE FALL в [[константы]]. Тесты: `check_tackle_in_place.gd`,
`check_player_visual_fall.gd`.

# Штрафной (Фаза A — `free_kick_controller.gd` + `free_kick_logic.gd`)

Общий контур стандартов, intent-шов, гейтинг — см. [[стандарты-и-intent-seam]].

## Что это

Клавиша **F** (`free_kick_debug`; гейт `_keeper_at(-field_length) != null and not _celebrating`). Точка
= позиция `controlled_player` в момент нажатия; мяч телепортируется туда; атакуемые ворота — Home на
`-field_length`. Автомат `IDLE → SETUP → AIM → STRIKE → WATCH → IDLE` — **единственный вместе с
[[пенальти]] с фазой WATCH** (фикс-камера держится `FK_WATCH_TIME` после удара; ранний выход, если мяч
уже не `is_flight()`).

Три опции: **прямой удар** (`kick`/D, с curl), **наземный пас** (`pass_short`/`pass_through`/X·W),
**навес** (`pass_lob`/A). Прицел стиком крутит heading в секторе ±`FK_AIM_ARC` (3.15 рад ≈ полный
оборот — для паса можно смотреть назад).

## `FreeKickLogic` — общий математический хаб стандартов

`class_name FreeKickLogic extends Object`, **не читает FootballConstants**. Его функции переиспользуют
[[угловой]], [[вбрасывание]], [[начальный-удар]]:

- `base_heading(from, goal_center)` · `rotate_heading(cur, base, stick_x, speed, dt, arc)` — прицел.
- `launch_velocity(heading, charge, min_speed, max_speed, min_elev, max_elev)` — вектор прямого удара.
- `scatter_degrees(charge, min, max)` · `apply_scatter(vel, deg, rng)` — разброс.
- `curl_from_stick(accum, scale, max_curl)` — curl-вектор из накопленного бокового ввода.
- `near_far_posts(...)` · `keeper_position(...)` — штанги и позиция вратаря по биссектрисе угла обстрела.
- `wall_count(...)` · `wall_line(...)` · `wall_body_positions(...)` · `wall_should_jump(...)` — стенка.
- `push_out_of_radius(pos, center, min_dist)` — выталкивание из радиуса (9.15м; переиспользуют вброс и
  кикофф).
- `push_out_of_cone(pos, apex, edge_l, edge_r, margin_deg)` — выталкивание из конуса мяч→края стенки.

## Размещение и тройная расчистка

Мяч на точку бьющего, `_pin_ball` держит его неподвижно всю AIM (штрафной берут «с ноги», остаточная
скорость укатила бы мяч). Бьющий за мячом на `FK_RUNUP_DIST`, латераль `FK_FOOT_LATERAL`.
1. `_clear_opponent_encroachment` — соперники дальше `FK_WALL_DIST + FK_ENCROACH_MARGIN`.
2. спавн стенки/тиммейтов.
3. `_clear_ball_to_wall_cone` — никто кроме бьющего/вратаря/стенки не в конусе мяч→края стенки.

Стенка авто-прыгает (`_update_wall_jumps`, дуга `sin(tt*PI)`, `FK_WALL_JUMP_HEIGHT`). На `_release`
стенка → `simple_ai`/team_2, тиммейты → `teammate_ai`/team_1 (тела не деспавнятся, вливаются в игру).

## Гочи

- **Единственный с curl** — закрутка копится ВСЮ дистанцию «нажатие kick → контакт», включая разбег
  (`_curl_accum`), фиксируется в `_on_kicker_contact`.
- `_apply_goal_magnet` подмешивает направление на центр ворот (`FK_GOAL_MAGNET`).
- Наземный пас/навес считают скорость из **дистанции** до получателя (`PassSystem.ground_pass_speed`,
  заряд лишь меняет жёсткость); навес правит горизонталь на драг через `KeeperLogic.drag_horizontal_speed`.
- Прячет/восстанавливает debug-болванки `WallDummy*`.
- ⚠️ Не задирай `FK_CURL_MAX` сильно выше 3.5: большой curl.z даёт Magnus-силу перпендикулярно текущей
  скорости каждый кадр — при избытке мяч «кружится на месте», а резкая смена `vel.z` уводит
  `KeeperLogic.shot_intercept` в фолбэк «летит от линии» → вратарь бежит к позиции мяча в поле, не к
  воротам.

несуществующие `FK_SPREAD_MIN_R`/`FK_MATE_OFFSET`). Тесты: `check_free_kick_logic.gd`,

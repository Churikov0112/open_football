# Настраиваемые константы

Сверено с `scripts/data/football_constants.gd` (autoload `FootballConstants`) **2026-07-28**.
Единственное место, где эта таблица должна жить, — здесь; другие страницы ссылаются сюда, а не
дублируют числа.

⚠️ **Хардкоды ВНЕ файла констант, которые тоже надо помнить:** `match_manager.gd` держит
`KICK_CHARGE_MAX_TIME = 0.5` и радиус удара `2.0` инлайном; тайминг ударных клипов
(`contact`/`lock`/`speed`/`post_speed`) — в `ACTION_TIMING` внутри `player_visual.gd`. Чистые
логики (`PassSystem`, `NetSim`, `KeeperLogic`, `*_logic.gd` стандартов) **никогда не читают
FootballConstants** — их «константы» приходят параметрами; проверяй значение у места вызова.

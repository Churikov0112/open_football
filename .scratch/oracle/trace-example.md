# Пример трассы и манифеста эталона

Status: reference
Type: notes

Снято с прогона `walk_line` (тикет 02, 2026-08-04). Потребитель — тикет 03: порт обязан выдавать файлы
той же формы. Источник истины по колонкам — [спека](./spec.md), раздел «Формат трассы»; здесь только
живой снимок, чтобы не гадать про пробелы, знаки и пустые поля.

## Трасса — `out/ref.csv`

1200 тиков × (1 строка мяча + 22 строки игроков) плюс заголовок = 27 601 строка, 4.5 МБ.

```
kind,tick,player_id,controlled,anim_name,anim_id,anim_type,function_type,frame_num,touch_frame,foot,enum_velocity,quadrant_id,pos_x,pos_y,pos_z,angle,rel_body_angle,move_x,move_y,move_z,action_smuggle,movement_smuggle
B,0,2.084130,-12.518356,0.110761,1.920240,-3.705092,-0.023230,,,,,,,,,,,,,,,
P,0,0,0,movement/dribble/angled/newangles/d135_to_d045_000_accel,1120,movement,1,5,-1,1,1,12,-40.591438,-2.894706,0.000000,-2.153248,-2.356194,-2.494812,1.643276,0.000000,0.000000,0.000000
P,0,1,0,autogen [v2 b45] => [v0 b0 a90]_mirror,840,movement,1,12,-1,1,0,0,-5.589744,19.447052,0.000000,0.523432,-0.000000,1.466751,-0.032997,0.000000,0.000000,0.000000
```

Контролируемый на нулевом тике — тот, у кого четвёртая колонка равна 1:

```
P,0,26,1,movement/idle/000_idlelevel1,1128,movement,1,0,-1,0,0,0,9.473575,1.655500,0.000000,-0.529856,-0.000000,0.000000,0.000000,0.000000,0.000000,0.000000
```

Правило нулевого тика видно прямо в строке: `anim_name` — idle-клип движения, `frame_num` (девятая
колонка) равен 0.

Что стоит заметить, читая это глазами:

- **23 поля в каждой строке файла, включая `B`.** У `B` заняты только первые восемь (`kind`, `tick`,
  позиция, момент), хвост — пустые поля, то есть 15 запятых подряд. Файл прямоугольный.
- **Имена колонок заголовка относятся к `P`-строке.** У `B` своя схема, и совпадение имён случайно:
  под именем `player_id` в `B`-строке лежит `ball_x`.
- **Пробелы и квадратные скобки в `anim_name` — норма**, это синтезированные имена автогенов
  (`autogen [v2 b45] => [v0 b0 a90]_mirror`). Запятых там нет по построению, и писатель падает, если
  вдруг встретит.
- **`touch_frame` равен −1**, когда у клипа нет касания. Ноль — это законный кадр касания, не «нет».
- **`rel_body_angle` печатается как `-0.000000`.** Это нормальный минус-ноль float, а не мусор;
  дифф сравнивает с допуском и его не заметит, но глазами это первое, что бросается.
- Порядок строк внутри тика: сначала `B`, затем `P` по возрастанию `player_id`.

## Манифест — `out/ref_manifest.csv`

1452 клипа плюс заголовок. Ровно тот размер `AnimCollection`, который спека называет ожидаемым.

```
index,anim_name,anim_type,foot,frame_count
0,autogen [v1 b0] => [v1 b0 a0]_mirror,movement,1,25
1,autogen [v1 b0] => [v1 b0 a0],movement,0,25
2,autogen [v1 b0] => [v1 b0 a45]_mirror,movement,1,25
...
1450,trip/trip_t3/walk/000_000,trip,0,87
1451,trip/trip_t3/walk/000_000_mirror,trip,1,87
```

- **Автогены идут первыми, файловые клипы — следом.** Порядок блоков у сторон уже совпадает:
  `GenerateAutoAnims` стоит до файлового цикла и в оригинале (`animcollection.cpp:400`), и в порте
  (`AnimCollection.cs:111`).
- **Зеркало идёт перед оригиналом** (`..._mirror` с индексом 0, оригинал с индексом 1) — так устроен
  цикл автогенов в оригинале, и порт это повторяет.
- `foot` — `e_Foot` как число: 0 = левая, 1 = правая (`animation.hpp:41-44`).
- `anim_name` нормализовано одинаково в трассе и в манифесте: путь относительно `animations/`, прямые
  слэши, нижний регистр, без `.anim`. У зеркал расширение стоит в середине сырого имени
  (`000.anim_mirror`), потому что `Mirror()` дописывает суффикс к готовому имени — после нормализации
  получается `000_mirror`.

## Как воспроизвести

Команды — в [run-commands.md](./run-commands.md). Второй сценарий, `rng_probe`, пишется тем же
писателем в `out/rng_ref.csv`; он намеренно трогает мяч (142 тика с `touch_frame >= 0` у
контролируемого, 111 тиков на клипах `ballcontrol` и 31 на `shortpass`) и с портом не сравнивается.

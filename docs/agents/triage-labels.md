# Метки триажа

Скиллы оперируют пятью каноническими ролями триажа. Эта таблица отображает роли в строки, которые
реально используются в трекере этого репозитория.

Трекер локальный (`.scratch/`, см. `issue-tracker.md`), поэтому «метка» здесь — это значение
строки `Status:` у верха файла тикета, а не лейбл GitHub. Унаследованной номенклатуры не было,
поэтому строки совпадают с каноническими именами.

| Роль в mattpocock/skills | Строка в нашем трекере | Значение                                     |
| ------------------------ | ---------------------- | -------------------------------------------- |
| `needs-triage`           | `needs-triage`         | Нужно оценить задачу                         |
| `needs-info`             | `needs-info`           | Ждём от постановщика недостающих сведений    |
| `ready-for-agent`        | `ready-for-agent`      | Полностью специфицирована, можно отдать агенту |
| `ready-for-human`        | `ready-for-human`      | Требует человека                             |
| `wontfix`                | `wontfix`              | Делать не будем                              |

Когда скилл упоминает роль (например, «примени метку AFK-ready»), бери соответствующую строку из
этой таблицы.

Правь правый столбец, если заведёшь свой словарь состояний.

## Что триажить, а что нет

Триаж — только для задач, которые **не ты создал**: баг-репорты, входящие пожелания, всё сырое.
Тикеты, произведённые `/to-tickets`, уже agent-ready — их триажить не надо.

Для этого проекта типичный вход триажа — находки после реального прогона игры (чувство игры
headless не ловит, см. `CLAUDE.md`) и расхождения порта с эталон-exe.
